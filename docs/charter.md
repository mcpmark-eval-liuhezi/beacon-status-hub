# Beacon Launch Charter

Scope: weekly status rollup for the Beacon launch

## Purpose

The charter of this repository is to provide a single, authoritative place to roll up
weekly status across the workstreams contributing to the Beacon launch.

## Cadence

- A status rollup is published every week.
- Each workstream contributes its updates by the agreed weekly cutoff.
- The rollup is published on the default branch of this repository.
