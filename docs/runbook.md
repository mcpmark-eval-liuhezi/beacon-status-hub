# Ops Runbook

Operational runbook for the Beacon launch status rollup hub.

## First Responder

The first responder for any alert or incident is the **on-call engineer**.

## Escalation

1. On-call engineer acknowledges the alert and triages.
2. If unresolved within the agreed window, escalate to the launch lead.
3. Record the incident and outcome in the weekly status rollup.
